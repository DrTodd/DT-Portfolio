# DT-Portfolio

This repository contains the code for my personal portfolio site. It’s a multi-page, responsive website built to showcase my work at the intersections of R&D, industry, policy and community.

## 🌐 Live Site

[drtodd.github.io/DT-Portfolio](https://drtodd.github.io/DT-Portfolio/)


## 🛠️ Technologies Used

- **Eleventy** – Run offline to create the static html site.
- **Photoswipe** – JavaScript image gallery and lightbox
- **GitHub Pages** – Static hosting
